# Website

This is a static website ready to be served from the root of a GitHub Pages site.

- `index.html` is the site entry point.
- `images.jpg` is displayed on the page.
- `Takopi Original Sin Ep 1.mp4` is intentionally excluded from Git.

The form is a visual example only; it has no backend and does not save submissions.

To publish, create a GitHub repository, add the website files except the ignored video, then enable GitHub Pages for the repository's main branch and root folder in **Settings > Pages**. A public repository makes its contents publicly accessible.
